Mã hóa / Giải mã RSA

Thực nghiệm các phép toán mật mã RSA chuyên sâu.

c = m^e mod n

m = c^d mod n

s = Hash(message)^d mod n

Hash(message) == s^e mod n

n → p, q → d = e^-1 mod phi(n)

Nhập n để hệ thống phân tích ra p, q, sau đó tính phi(n) và tìm d. (Chỉ áp dụng cho n nhỏ)
